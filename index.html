< The program />

The study program of Vefskólinn is divided into 8 modules.

01

Intro to web dev

2 weeks
  • Basic guides in design and coding (HTML & CSS)
  • One week group project
02

Community module

all year
  • Students work on this the whole time
03

Web dev basics

+ 2-week project
  • Introduction to JavaScript
  • Introduction to UX and UI
  • Two-week group project
04

External services

+ 3-week project
  • Introduction to JS frameworks
  • Design thinking & responsive web
  • Three-week group project
05

Back-end development

2 + 2 weeks
  • Guides for 2 weeks
  • Group project for 2 weeks
06

Advanced topics

+ 4-week project
  • Combine everything you've learned in JS
  • Advanced design thinking & deep UI
  • Four-week group project
07

Specialization project

solo
  • Individual deep-dive on a topic of your choice
08

Internship

12 weeks
  • Real work in a real Icelandic agency

< Design />

There are two aspects of design at Vefskólinn.

UX — User Experience

We focus on what the user experiences on our website. The flows, the friction, the feel.

UI — User Interface

We focus on the visual aspects of our website. Colour, type, hierarchy, motion.
